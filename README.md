# Banking App

A modern, clean, and professional Cambodian banking application built with Flutter.

## Features

- **Authentication**: Welcome, Login, Sign Up, Terms & Conditions, and Forgot Password screens
- **Dashboard**: User dashboard with account overview and quick actions
- **Messages**: Facebook Messenger-style chat interface
- **Notes**: Note-taking functionality with list and detail views
- **Notifications**: Notification center with categorized notifications
- **Profile**: User profile management with image upload
- **Transactions**: Transaction history and management
- **Cards**: Card management
- **Bills**: Bill payment functionality
- **Transfer**: Money transfer features
- **Deposit/Withdraw**: Account deposit and withdrawal
- **QR Scanner**: QR code scanning functionality
- **Exchange Rate**: Currency exchange rates
- **Settings**: App settings and preferences

## Design

The app features a clean, modern, and professional UI inspired by ABA Bank, ACLEDA, and Wing Bank, with:
- Orange accent color theme
- Smooth animations and transitions
- Responsive layouts
- Keyboard-aware scrolling
- Professional typography

## Getting Started

### Prerequisites

- Flutter SDK (latest stable version)
- Dart SDK
- Android Studio / VS Code with Flutter extensions

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Kimheang-code-IT/banking_app.git
cd banking_app
```

2. Install dependencies:
```bash
flutter pub get
```

3. Run the app:
```bash
flutter run
```
